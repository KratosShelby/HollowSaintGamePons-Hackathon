# Hollow Saint — Art Direction

**Style:** Duotone pixel noir. Warm amber/orange light sources against cool navy/purple shadow and ambient color. Closest direct references: ref images 15, 6, 7 (trenchcoat-and-hat silhouette under a streetlamp, cold dark city/room around it).

## Palette

- **Base/shadow:** deep navy / near-black (cool)
- **Light source color:** warm amber/orange — every light source in the game (streetlamp, lamp, radio dial, match/cigarette) uses this
- **Reserved accent (supernatural only):** one color never used anywhere in the "normal" world — sickly violet or green. Used exclusively for clue glow, entity tells, and the final mirror reveal (Dutch's reflection uses it for the first time in the whole game). This is a mechanic as much as a palette rule — players learn "that color = something's off" for free, through consistent use, no tutorial text needed.

## Character design

- Dutch Marlowe: coat + hat silhouette should read as "detective" even in shadow, no facial detail needed. Reference 10 (`#2.SUIT` by @mystmoir) — face left blank/shadowed under the hat brim entirely. Cheap to animate (no face), and quietly on-theme (identity left deliberately undefined until the twist).

## Resolution & technique

- Low native render resolution (~320x180), nearest-neighbor scaling, no antialiasing
- Hard-edged dithered shadow transitions instead of smooth gradients (cheap to produce by hand once 1-2 dither patterns are made, reusable everywhere)

## UI direction

- **The Book / case file UI** should look like an actual case file document, not a generic menu: stamps, redacted bars, mugshot-style photo framing. Reference 24 (police case file layout).
- Inventory/tool-select can sit alongside The Book as a simple icon row (reference 11's HUD: gun + book icons together) — The Book itself should be one of the "items" the player always carries, visually.

## Room composition (opening scene reference)

- Small, cramped, slightly off-center rather than symmetric
- One key light source (venetian blind window, or a single streetlamp-style lamp) casting hard directional light/shadow stripes
- Sparse props only: bed, desk with newspaper, mirror on wall, radio on nightstand
