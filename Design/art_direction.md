# Hollow Saint — Art Direction

**Style (revised — no longer pixel art):** hand-painted noir illustration, semi-realistic. Warm amber/orange light sources against cool navy/purple shadow and ambient color. Closest references: #20 (soft painted shading, visible brush texture), #22 (detective at a desk, venetian-blind light — direct template for the hotel room), #25 (dramatic directional silhouette light). Refs #12/#15/#6/#7 were the original pixel-art mood references and no longer apply as a technique — their color/mood still informs the palette below, but don't aim for their blocky rendering.

## Palette

- **Base/shadow:** deep navy / near-black (cool)
- **Light source color:** warm amber/orange — every light source in the game (streetlamp, lamp, radio dial, match/cigarette) uses this
- **Reserved accent (supernatural only):** one color never used anywhere in the "normal" world — sickly violet or green. Used exclusively for clue glow, entity tells, and the final mirror reveal (Dutch's reflection uses it for the first time in the whole game). This is a mechanic as much as a palette rule — players learn "that color = something's off" for free, through consistent use, no tutorial text needed.
- This is a color *family* to stay inside, not a locked set of exact hex values — real gradients and tonal range within it are expected now that it's painted rather than pixel art.

## Character design

- Dutch Marlowe: coat + hat silhouette should read as "detective" even in shadow, no facial detail needed. Reference 10 (`#2.SUIT` by @mystmoir) — face left blank/shadowed under the hat brim entirely, deliberately (identity left undefined until the twist), not a fidelity shortcut. Everything else about him — coat, posture, light on the fabric — can be as rendered/realistic as the references.

## Rendering technique

- No pixel grid, no nearest-neighbor scaling, no forced low resolution — render at whatever fidelity reads like the references.
- One directional light source per room, casting real shadow across the whole scene — hard-edged/dithered or soft-edged, whichever reads better per scene — instead of flat-lit props on a flat floor. This is the single technique that closes the gap between "looks like the references" and "looks like generic placeholder art."

## UI direction

- **The Book / case file UI** should look like an actual case file document, not a generic menu: stamps, redacted bars, mugshot-style photo framing. Reference 24 (police case file layout).
- Inventory/tool-select can sit alongside The Book as a simple icon row (reference 11's HUD: gun + book icons together) — The Book itself should be one of the "items" the player always carries, visually.

## Room composition (opening scene reference)

- Small, cramped, slightly off-center rather than symmetric
- One key light source (venetian blind window, or a single streetlamp-style lamp) casting hard directional light/shadow stripes
- Sparse props only: bed, desk with newspaper, mirror on wall, radio on nightstand
